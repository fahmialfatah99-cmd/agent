## 4. Desain Kunci (Key Patterns)

### Provider Interface (satu file, ~30 baris)
```python
# providers/base.py
from abc import ABC, abstractmethod

class BaseProvider(ABC):
    @abstractmethod
    async def chat(self, messages: list[Message], **kwargs) -> Stream:
        ...

    @abstractmethod
    async def embed(self, texts: list[str]) -> list[list[float]]:
        ...

    @abstractmethod
    def supports(self, feature: str) -> bool:
        ...
```

### Agent Loop (ReAct + Reflection)
```
User Input
   → Router (klasifikasi intent)
   → Planner (pecah jadi sub-tasks)
   → Reasoner (pilih tool + chain-of-thought)
   → Executor (jalankan tool, dapat result)
   → Reflector (eval hasil, retry jika gagal, max 3x)
   → Response
```

### Tool Registry (auto-discovery)
```python
# tools/registry.py
class ToolRegistry:
    def register(self, tool: BaseTool): ...
    def get(self, name: str) -> BaseTool: ...
    def list_schemas(self) -> list[dict]: ...  # Untuk function calling
```

## 5. Stack Rekomendasi

| Layer | Teknologi |
|-------|-----------|
| Frontend | Next.js 15, Tailwind CSS, Framer Motion, Zustand, shadcn/ui |
| Backend | FastAPI, Python 3.12, Pydantic v2 |
| Vector DB | Qdrant (self-host) / Pinecone |
| Cache | Redis (conversation, rate-limit) |
| Queue | Celery / BullMQ (async tasks) |
| DB | PostgreSQL (users, configs, logs) |
| Streaming | SSE / WebSocket |
| Monorepo | Turborepo / pnpm workspaces |
| Deploy | Docker Compose → Fly.io / Railway |

## 6. Mulai Dari Mana?

**Urutan eksekusi prioritas:**

```
1. providers/base.py + openai.py     → bisa chat dulu
2. core/reasoner.py + executor.py    → agent bisa pakai tool
3. core/planner.py + reflector.py    → jadi "super intelligent"
4. memory/short_term.py + long_term.py → punya ingatan
5. api/routes/chat.py                → expose endpoint
6. web/app/(chat)/page.tsx           → UI pertama
7. Sisanya iteratif                  → polish & scale
```
